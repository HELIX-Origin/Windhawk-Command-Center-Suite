# Extras Companion Mod Configurations

This directory contains companion mod configurations for the Windhawk Command Center Suite. These configurations extend and complement the primary mods, providing additional customization options for various Windows shell surfaces.

## Supported Companion Mods

- **Dynamic Isnald for Windows**: Provides dynamic island functionality for Windows, enhancing multitasking and notifications.
- **Taskbar Clock Customization**: Allows you to customize the appearance and behavior of the taskbar clock.
- **Shell Flyout Positions**: Lets you adjust the positions of various shell flyouts for a more personalized experience.
- **Taskbar Tray and Icon Tweaks**: Provides options to modify the taskbar tray and icons to suit your preferences.
- **Fully Customizeable Winver**: Enables full customization of the Winver dialog, including text and appearance.
- **Start Button Colorizer**: Allows you to change the color of the Start button to match your theme.
- **Enhanced Disk Usage**: Provides detailed disk usage information and visual enhancements for better monitoring.
- **File Operations Styler**: Lets you customize the appearance and behavior of file operation dialogs.
