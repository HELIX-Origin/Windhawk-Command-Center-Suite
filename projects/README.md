# Projects (`projects/`)

This directory contains per-project theme subfolders. Each subfolder hosts the full suite of styler files, companion extras, and assets for a specific Windhawk theme.

---

## Structure

```
projects/
├── <project-name>/                     # Per-project theme workspace
│   ├── windows-11-start-menu-styler.yml
│   ├── windows-11-taskbar-styler.yml
│   ├── windows-11-notification-center-styler.yml
│   ├── windows-11-file-explorer-styler.yml   (if implemented)
│   ├── windows-11-settings-styler.yml        (if implemented)
│   ├── extras/                               # Companion mod configs & assets
│   └── README.md                             # Project overview & installation guide
```
